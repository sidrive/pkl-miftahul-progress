# Live Coding — Cek Stok Barang (Evaluasi `M2.W3.T7`)

> ⚠️ **Khusus mentor.** Folder ini berisi spec, starter file, dan referensi jawaban untuk sesi live
> coding evaluasi. **Jangan diberikan/ditunjukkan ke Gazi sebelum sesi berlangsung** — tujuannya
> memverifikasi dia bisa menggabungkan skill Minggu 2 (array methods, DOM, event delegation) dan
> Minggu 3 (Promise/`async`/`await`) secara live, tanpa persiapan sebelumnya.
>
> **Belum di-merge ke `main`** — folder ini sengaja ditahan di branch `feature/mentor` sampai sesi
> evaluasi selesai, supaya tidak kebaca Gazi lebih dulu (dia punya akses ke `main`).

## Isi folder

- [`spec.md`](./spec.md) — brief task lengkap: requirement, 2 tingkat kompleksitas, rubrik
  penilaian, estimasi waktu.
- [`starter.html`](./starter.html) — file yang **diberikan ke Gazi** saat sesi dimulai (cuma
  skeleton HTML, tanpa logic JS).
- [`data-contoh.js`](./data-contoh.js) — data barang yang didiktekan/ditempel saat sesi (biar dia
  tidak buang waktu mengetik data, fokus ke logic).
- [`referensi-jawaban.js`](./referensi-jawaban.js) + [`referensi-jawaban.html`](./referensi-jawaban.html) —
  **kunci jawaban mentor**, tingkat dasar (berjalan penuh) + lanjutan (dikomentari sebagai
  alternatif). Buka `referensi-jawaban.html` di browser untuk lihat langsung hasilnya jalan. Bukan
  untuk ditunjukkan, cuma pembanding kalau Gazi stuck dan Anda perlu tahu arah yang benar dengan
  cepat.

## Alur singkat sesi

1. Kasih `starter.html` + `data-contoh.js` ke Gazi, minta dia salin datanya ke script.
2. Jelaskan requirement tingkat dasar (lihat `spec.md`) secara lisan — jangan kasih file spec ini.
3. Amati proses, pakai rubrik di `spec.md` untuk menilai pilihan array method, cara render DOM,
   dan pola event listener yang dia pakai.
4. Kalau dia selesai jauh sebelum waktu habis, lanjut ke tingkat lanjutan (loading state async).
5. Setelah sesi, folder ini boleh diarsipkan atau dihapus dari `feature/mentor` kalau tidak
   diperlukan lagi untuk minggu berikutnya.
